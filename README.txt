HOMCO INTERIOR - LARAGON PHP + MYSQL

1. Copy the homco folder into C:\laragon\www\
2. Start Apache and MySQL in Laragon.
3. Open http://localhost/phpmyadmin
4. Import database.sql (or paste it in SQL tab).
5. Open http://localhost/homco/

FOLDERS
config  = database/session/shared layout
assets  = CSS + images
guest   = public website pages
user    = logged-in user panel
admin   = admin panel
auth    = login/register/forgot/logout

NOTE
This is a native PHP/MySQL Laragon project. Images extracted from the supplied HOMCO PDF are included in assets/images. The UI follows the supplied design: green accent, black/white layout, hero, service cards, portfolio gallery, testimonials, CTA and dark footer.
